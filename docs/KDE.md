# KDE Plasma apps

Practical KDE utilities installed by [`scripts/setup-kde.sh`](../scripts/setup-kde.sh)
(Arch/CachyOS). No theming — plain Plasma.

| Package | Why |
|---------|-----|
| `partitionmanager` | GUI disk/partition manager |
| `yakuake` | Drop-down terminal (**F12** to toggle) |
| `kate` | Text editor |
| `ark` | Archive manager |
| `okular` | Document/PDF viewer |
| `gwenview` | Image viewer |
| `kdeconnect` | Phone ↔ desktop |
| `kio-extras` / `ffmpegthumbs` / `kdegraphics-thumbnailers` | Thumbnails + extra KIO protocols in Dolphin |
| `xdg-desktop-portal-kde` | Screen share / file picker for Wayland apps |
| `noto-fonts` / `noto-fonts-emoji` / `ttf-jetbrains-mono` | Unicode, emoji, monospace |
| `papirus-icon-theme` | Icon set |

Handy Plasma built-ins: **Meta+T** toggles window tiling; enable Blur/Rounded
Corners under System Settings → Desktop Effects if you want them.
